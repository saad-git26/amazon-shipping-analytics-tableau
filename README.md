#  Amazon Shipping Analytics Dashboard

A simple and clean **Tableau dashboard** that tracks Amazon order shipping performance for **April 2020**.

##  Project Goal
To answer a few simple business questions:
1. How many orders were placed, and how many were not shipped?
2. What percentage of orders is not shipped?
3. Which product categories have the most orders?
4. On which days and in which countries do unshipped orders occur?

##  Dashboard Highlights
- **KPI Cards:** Total Order Count, Count of Orders not Shipped, % Not Shipped
- **Bar Chart:** Total orders by product category (Shipped vs Not Shipped)
- **Line Chart:** Daily trend of shipped orders
- **Line Chart:** Daily trend of not shipped orders
- **Map:** Not shipped orders by country
- **Filters:** Order Date (month) and Is Shipped (Yes / No)

##  Key Numbers (April 2020)
